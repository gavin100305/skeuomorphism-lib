# skeumorphism-lib

A standalone project for a skeuomorphic React component library and its documentation site. This repository is independent of the portfolio project.

## Stack

- Next.js App Router
- React and TypeScript
- Tailwind CSS
- ESLint
- npm

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000. If another app uses that port, run:

```bash
npm run dev -- --port 3001
```

## Commands

```bash
npm run dev    # Start development
npm run build  # Create a production build
npm start      # Serve the production build
npm run lint   # Run ESLint
```

The initial commit contains the Next.js starter. Components and the registry will be added separately.
