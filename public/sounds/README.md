This short excerpt contains the A, S, D, and F key press/release samples used by the reference keyboard.


## Clock rim

`clock-tick.wav` contains two trimmed, faded, mono, peak-normalized clock ticks from [Tick2.ogg](https://commons.wikimedia.org/wiki/File:Tick2.ogg) by [Marble Toast](https://commons.wikimedia.org/wiki/User:Marble_Toast), released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Source recording: https://upload.wikimedia.org/wikipedia/commons/f/fa/Tick2.ogg

The website preloads this file and alternates the two ticks when the rim is adjusted. It follows the interface sound toggle. Installable components still use a host-supplied `onTurnSound` callback and do not fetch website audio assets.
